# 받아쓰기(Whisper) 오인식 교정표 — prep.py 가 설교원고.txt 를 만들 때 적용한다
# 형식:  틀린말 → 바른말   (위에서부터 차례로 바꾼다. 문맥 없이 바꿔도 안전한 것만 적을 것)
# 매주 원고를 고치다 새로 나온 오인식은 여기에 한 줄 추가한다.

고린도구서 → 고린도후서
고림도 → 고린도
고린도교의 → 고린도 교회의
스토리교의 → 스토리교회의
무사람 → 뭇사람
무스람 → 뭇사람
말미야마 → 말미암아
그리스로 → 그리스도
그리소 → 그리스도
그리스께서 → 그리스도께서
그리스의 편지 → 그리스도의 편지
그리스의 증 → 그리스도의 증
불안하셔서 → 부활하셔서
갱그리아 → 겐그레아
베베 → 뵈뵈
천거선을 → 천거서를
